## New ways to map, explore, and export SDK intelligence

AppGoblin's SDK dataset is growing quickly, and these new features make it easier to fill mapping gaps, investigate SDK patterns, and save useful results for later.

## Free: Request company and SDK mappings

Know a company domain that is not mapped yet? Or found an SDK package, manifest entry, or other SDK signal that should be associated with a company?

You can [contact AppGoblin](/contact) to request a company-domain mapping or an unmapped SDK part. These requests help improve the dataset for everyone and are available without a paid plan.

## Free: Explore any SDK pattern

The [SDK analysis area](/sdks) lets you view any SDK pattern and inspect the evidence behind it. Open a pattern to see matching SDK parts, associated companies where available, and a sample of matching apps.

This is useful when you are researching an unfamiliar package name, manifest value, file path, or other SDK fingerprint. You can start with a pattern from the SDK overview or navigate directly to a pattern page such as [`/sdks/<pattern>`](/sdks).

## Premium: Export every app matching an SDK pattern

Need the complete list rather than an on-page preview? B2B SDK Intelligence and Premium users can generate a full CSV report from any SDK pattern page. AppGoblin processes the complete matching dataset and emails a download link when the report is ready.

Generated SDK pattern reports are also saved to the new [Generated Reports](/account/reports) section of your account, so you can return to them later instead of repeating the export.

## Premium: Save App Explorer reports

The [App Explorer](/app-explorer) can search the app dataset using filters such as company SDKs, categories, stores, install counts, ratings, and monthly installs. Premium users can now generate a report and find it again in [Generated Reports](/account/reports).

This gives you one place to revisit both full SDK pattern exports and App Explorer reports. Download links are available from your account whenever you need the data again.
